# 쥐와 치즈로 배우는 A* 탐색

저장소 루트에서 아래 명령으로 실행합니다. Python의 Tkinter를 사용합니다.

```powershell
python python/astar_maze/simulation.py
```

**한 단계**를 누르면 A*가 다음 후보 한 칸을 선택합니다. 보라색 후보 칸의 숫자는 `f`이고, 오른쪽에는 선택한 칸의 좌표와 `g`, `h`, `f`가 표시됩니다. 최단 경로를 찾은 뒤에는 한 단계마다 쥐가 노란 경로를 따라 한 칸 이동합니다. **자동 재생**으로 전체 과정을 볼 수 있습니다.

## 미로 설정

- **크기**에서 11×15부터 23×33까지 네 가지 행·열 조합을 고를 수 있습니다.
- **복잡도**는 쉬움·보통·어려움 중에서 고릅니다. 생성된 미로에서 복잡도만 바꾸면 같은 구조를 바탕으로 지름길 수가 바뀝니다. 쉬움에 지름길이 가장 많고, 어려움에서는 치즈까지 가는 경로가 하나입니다.
- **새 미로**는 선택한 크기와 복잡도로 다른 미로를 생성합니다. **처음으로**는 지금 미로의 탐색만 초기화합니다. 큰 미로에서는 재생 속도를 **아주 빠르게**로 올릴 수 있습니다.

## 알고리즘 읽기

[astar.py](astar.py)의 `astar()`가 후보를 선택할 때마다 `SearchStep`을 하나씩 반환합니다. [simulation.py](simulation.py)는 그 상태를 미로 화면에 그립니다.

| 값 | 뜻 |
| --- | --- |
| `g` | 출발점부터 현재 칸까지 찾은 경로의 이동 횟수 |
| `h` | 벽을 무시했을 때 현재 칸에서 치즈까지의 거리. `행 차이의 절댓값 + 열 차이의 절댓값`으로 계산합니다. |
| `f = g + h` | 출발점에서 현재 칸을 거쳐 치즈까지 가는 비용의 추정치 |

1. `heapq`에서 `f`가 가장 작은 칸을 꺼냅니다. `f`가 같으면 `h`, 행, 열 순서로 비교합니다. 좌표는 0부터 셉니다.
2. 상하좌우 통로를 확인합니다. 이웃 칸에 더 짧게 갈 수 있으면 `best_g`와 이전 칸을 기록하는 `parent`를 갱신합니다.
3. 치즈 칸을 꺼내면 `parent`를 출발점까지 거슬러 올라가 최단 경로를 만듭니다.

실행 직후의 예제에서 쥐의 출발점은 `(1, 1)`, 치즈는 `(9, 13)`입니다. `h`는 `8 + 12 = 20`이고, 벽을 돌아가는 최단 경로에서는 46회 이동합니다. 첫 단계에서 `f`가 같은 두 후보가 생겼을 때 어느 칸이 먼저 선택되는지 확인해 보세요.

## 쥐의 미로 탈출 (DFS)

```powershell
python python/astar_maze/escape_simulation.py
```

기본은 31×47 어려움 미로입니다. 최대 41×61까지 고를 수 있습니다. 실행할 때마다 출구를 무작위로 정합니다. **새 미로**를 누르면 통로를 새로 만들고 외벽의 다른 위치에 출구를 엽니다. 복잡도만 바꾸면 출구 위치를 유지한 채 지름길 수를 비교할 수 있습니다.

**한 단계**를 누를 때마다 쥐가 전진하거나 되돌아갑니다. 시작 화면은 쥐가 확인한 벽과 통로만 표시합니다. **전체 미로 보기**를 켜면 수강생은 처음부터 미로와 출구를 볼 수 있습니다. 노란색은 스택에 남은 경로, 보라색은 되돌아 나온 통로, 초록색은 출구입니다.

[escape_dfs.py](escape_dfs.py)의 핵심 함수는 `explore(start, sense)`입니다. 시뮬레이터는 미로를 보관하고, `sense`를 통해 쥐가 선 칸의 출구 여부와 바로 옆 네 칸의 통과 여부만 알려 줍니다. DFS는 오른쪽·아래·왼쪽·위 순서로 처음 가 보는 통로를 찾아 움직입니다. 탐색은 한 칸씩 진행되며 최단 경로는 보장하지 않습니다.

1. 새 칸으로 전진할 때는 `visited`에 방문을 기록하고 `stack.append()`로 현재 경로에 칸을 추가합니다.
2. 더 갈 곳이 없으면 `stack.pop()`으로 현재 칸을 꺼내고 스택 맨 위의 이전 칸으로 돌아갑니다. 방문 기록을 유지하므로 같은 막다른 길을 다시 탐색하지 않습니다.
3. `E`가 표시된 칸에 들어가면 탈출에 성공합니다. 화면의 이동 횟수에는 되돌아간 횟수도 포함됩니다.
